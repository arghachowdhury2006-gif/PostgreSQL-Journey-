# Employee Database 🐘

Creating an employee table and working with datatype, constraints and default values.

## Concepts Learned

- Creating tables with `CREATE TABLE`.
- Using `SERIAL` and `PRIMARY KEY`.
- Applying `NOT NULL` and `UNIQUE` constraints.
- Setting default values using `DEFAULT`.
- Working with `DECIMAL` and `DATE` data types.
- Using `CURRENT_DATE` as a default date.
- Inserting single and multiple employee records.
- Retrieving records using `SELECT`.

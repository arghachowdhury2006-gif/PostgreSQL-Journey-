# Foreign Keys & SQL Joins 🐘

Creating related tables and practicing joins to retrieve data from multiple tables.

## Concepts Learned

- Creating related tables using `CREATE TABLE`.
- Using `PRIMARY KEY` and `FOREIGN KEY`.
- Establishing relationships using `REFERENCES`.
- Inserting customer and order records.
- Retrieving data using `SELECT`.
- Combining tables using `CROSS JOIN`.
- Retrieving matching records using `INNER JOIN`.
- Using `LEFT JOIN` and `RIGHT JOIN`.
- Calculating total order prices using `SUM()`.
- Grouping records using `GROUP BY`.

# Filtering, Sorting & Aggregation 🐘

Practiced basic SQL queries for working with employee data.

## Concepts Learned

- `WHERE` - Filter data
- `AND / OR` - Combine conditions
- `IN` - Match multiple values
- `BETWEEN` - Find values in a range
- `DISTINCT` - Show unique values
- `ORDER BY` - Sort data
- `LIMIT` - Limit results
- `LIKE` - Search patterns
- `COUNT, SUM, AVG, MIN, MAX` - Aggregate functions
- `GROUP BY` - Group data
